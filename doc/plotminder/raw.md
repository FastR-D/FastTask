# 背景
根据史蒂芬•科维的“四象限法则”，事情可以分为四个象限，即重要不紧急，重要且紧急，不重要不紧急，不重要但紧急，或者说有紧急程度和重要程度两个维度。

# 想法
1. 我的出发点是新建一个坐标轴二维地图，将所有待办事项作为点展示在坐标上，方便用户直观感受有哪些事情。
2. 随后，我想到可以增加第三个维度，创建一个三维地图，依然可以方便地进行可视化，而第三个维度的评价可以由用户自定义，比如喜爱程度
3. 随后，再扩散一点，前两个维度都可以由用户自定义，这样这个地图就可以用作reminders之外的事情。比如用户需要记录自己的想法，那么就可以有“符合自己喜好成都”“符合大众要求成都”“能够带来经济价值的程度”，这样用户就可以更加直观地整理自己的想法
4. 然后，只是将事项列出来还是静态场景，就像做旅游攻略一样，这是需要到达的目标。那么我们还可以添加动态解决方案，即向用户展示先做什么，再做什么，最后做什么，就像导航一样，建议用户先要去哪里，然后去哪里，最后去哪里。这样用户可以直观地知道自己应该怎么做。
5. 既然有了路径，那么就可以设置时间节点和提醒事项，就像导航一样，提醒用户现在应该做什么，然后可以同步用户实际进度，甚至可以像导航一样即时调整路线，调整计划，这都可以支持。
