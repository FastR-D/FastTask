# Feature Spec: P5 Live Mode & Reflect

**Phase**: P5
**Milestone**: v1.0 Public
**Status**: Draft
**Created**: 2026-05-19
**Constitution Compliance**: v1.0.0
**Dependencies**: P0, P1, P2, P3, P4

---

## 1. 概述

P5 完成 v1.0 的最后一片拼图:**时间作为可选属性、番茄追踪、路径执行中的重规划建议、周复盘 Reflect**。

P5 是产品长期粘性的来源。前 4 个 phase 让 Plotminder 好用,P5 让用户**愿意持续用 6 个月以上**。The Reflect 用户时刻在此 phase 实现。

P5 最微妙的设计点:**时间属性必须存在(用户需要 deadline 提醒),但严禁让时间偷偷成为隐形主轴**(宪章 II)。这是本 phase 全程要保护的边界。

成功标志:**用户连续使用 4 周后,周日晚上 Reflect 自动弹出,用户主动期待这个时刻,且 Reflect 内容让他看见自己被紧急挟持的真相**。

---

## 2. 用户故事

- **US-P5-1** 作为用户,我能为 task 设置可选的 `deadline`、`duration estimate`、`scheduled_at`,这些字段是**属性**,不影响路径推荐顺序。
- **US-P5-2** 作为用户,我能在 task 上启动一个番茄计时(25 分钟默认),计时结束后弹小提示。
- **US-P5-3** 作为已集成 Toggl 的用户,我的番茄数据自动同步到 Toggl。
- **US-P5-4** 作为执行路径的用户,我能主动点击"重规划"按钮,系统根据当前 task 状态生成新的推荐路径——但**只在我主动触发时**。
- **US-P5-5** 作为用户,周日晚 20:00(可配置),Plotminder 弹出 Reflect 周复盘 UI,包含本周地图对比、热力图、AI 一句话总结。
- **US-P5-6** 作为用户,我能在 Reflect 中播放本周地图的 7 天演变动画,看到任务如何在 axis-space 中流动。
- **US-P5-7** 作为用户,Reflect 给我的 AI 总结永远是**建议**口吻("建议下周给左上区至少 3 个节点"),不是命令。
- **US-P5-8** 作为用户,我能跳过任何一周的 Reflect(不强制弹出),且能在历史中翻看过去几周的 Reflect。

## 3. 功能需求

### 3.1 时间属性

- **FR-P5-001** Task 新增可选字段:
  - `deadline`: timestamp (UTC) 或 null
  - `duration_estimate`: 分钟数,默认 null
  - `scheduled_at`: timestamp (UTC) 或 null(用户主动安排时间块)
- **FR-P5-002** 这些字段**不进入路径推荐算法**——除非用户**显式**把"时间紧迫程度"添加为某 view 的轴(此时该轴的值由系统根据 deadline 自动计算映射,逻辑独立模块)。
- **FR-P5-003** Deadline 提醒:用户能配置每个 task 是否需要 deadline 提醒;到期前 N 小时弹通知(默认关)。
- **FR-P5-004** Detail panel 显示这些字段,但**不在地图节点上以醒目方式呈现**(避免成为视觉主因)。
- **FR-P5-005** 提供一个独立的"时间属性"视图(列表 + 按 deadline 排序),作为可选辅助视角——**不是默认 view**。

### 3.2 番茄计时

- **FR-P5-006** 在 task 上点击"开始番茄"按钮,弹出计时浮窗(默认 25min 工作 + 5min 休息)。
- **FR-P5-007** 番茄期间该 task 的 status 自动切换为 `doing`(用户主动启动,符合宪章 I.3)。
- **FR-P5-008** 番茄结束:轻微声音 + 通知 + 短暂动画,询问"完成?继续?中断?"。
- **FR-P5-009** 番茄数据写入 task 的 `time_log` 字段(每个番茄一条:开始、结束、是否完成、备注)。
- **FR-P5-010** 番茄计时本地完成,不依赖任何外部服务。
- **FR-P5-011** 可选 Toggl 集成:开启后每个番茄自动 push 到 Toggl 工作区(双向同步通过 P4 adapter 框架)。
- **FR-P5-012** 番茄计时**不**自动调整路径推荐——用户完成一个番茄后,The Decide 不会因此重排顺序。

### 3.3 重规划建议

- **FR-P5-013** "重规划"按钮在以下情况显示:
  - 用户点击"现在做啥"时,如检测到推荐路径中部分 task 已过 deadline,或用户已拒绝多次,**建议**重规划(显示按钮,**不**自动触发)
  - 用户主动在工具栏点击"重规划"
- **FR-P5-014** 重规划是一次普通的路径推荐重算(P3 的算法),只是入口不同;不包含任何"AI 决定要不要重规划"的逻辑。
- **FR-P5-015** 重规划可弹出对话框,让用户选择"以当前 view 的坐标重算" / "切换到另一个 view 重算" / "调整轴权重后重算",但**不**自动选择。

### 3.4 Reflect 周复盘

- **FR-P5-016** Reflect 触发:默认本地时间**周日 20:00**;用户可在 Settings 配置日期与时间。
- **FR-P5-017** Reflect UI 包含四个核心 widget:
  1. **本周 vs 上周地图对比** — 左右并列两张地图,标注差异
  2. **7 天演变动画** — 可播放的时间轴,看 task 如何在 axis-space 中移动
  3. **完成节点热力图** — 本周已完成节点在 axis-space 的密度分布
  4. **AI 一句话总结** — 建议口吻,基于本周分布
- **FR-P5-018** AI 总结 prompt 输入包含:本周完成数量、热力图象限分布、上周对比、用户配置的"理想分布"(可选)。
- **FR-P5-019** AI 总结输出限制:
  - 长度 ≤ 150 字符
  - **必须**以建议口吻("可以考虑..."、"下周或许...")而非命令
  - **禁止**包含具体的某个 task 名(避免侵入性提及私事)
- **FR-P5-020** Reflect 历史:每周生成一次,持久化存储,可在历史 tab 翻看过去任意一周。
- **FR-P5-021** 用户能在 Reflect 中点击"跳过本周"、"提醒我明天",或永久关闭自动弹出(仍可手动打开)。
- **FR-P5-022** Reflect 不强制阻塞——弹出窗口可关闭,不要求用户操作完才允许使用应用。

### 3.5 跨 view 的 Reflect

- **FR-P5-023** Reflect 默认聚焦"主 view"(用户使用频率最高的 view,系统自动判断,可手动覆盖)。
- **FR-P5-024** Reflect 中能切换其他 view 的复盘视角。

### 3.6 数据隐私

- **FR-P5-025** AI 总结调用 LLM 时,**不**传输任何 task title、description、note 的原文,只传输统计量(数量、分布、坐标聚合)。
- **FR-P5-026** 用户可在 Settings 关闭 AI 总结,Reflect 中相应 widget 隐藏,其他 widget 不受影响。

---

## 4. 非功能需求

- **NFR-P5-001** Reflect 加载完整数据 < 1 秒(中型 workspace,1000 tasks)。
- **NFR-P5-002** 7 天演变动画播放流畅(30fps+)。
- **NFR-P5-003** 番茄计时不依赖任何外部服务,完全离线可用(宪章 V.2)。
- **NFR-P5-004** 重规划计算 P95 < 100ms(与 P3 路径推荐相同基准)。
- **NFR-P5-005** AI 总结调用失败时,Reflect 仍可显示其他三个 widget,不阻塞。

---

## 5. 验收标准

- **AC-P5-1** 给某 task 设置 deadline 为今天,推荐路径**不**因此把它排到第一;**仅当**用户已显式把"时间紧迫程度"添加为轴时,该 task 才因 deadline 进入路径前列。
- **AC-P5-2** 启动番茄,中途切到其他应用,计时持续;25 分钟到达时通知触发。
- **AC-P5-3** 周日 20:00 自动弹出 Reflect,用户能看到完整四个 widget。
- **AC-P5-4** Reflect 中 7 天演变动画播放完整,完成节点的"轨迹"可见。
- **AC-P5-5** AI 总结遵守口吻约束(reviewer 评估 10 条样本均为建议口吻,非命令)。
- **AC-P5-6** 关闭 AI 总结后,Reflect 仍正常显示其余 widget。
- **AC-P5-7** Reflect 历史 tab 能翻看过去 12 周(若有数据)。
- **AC-P5-8** 番茄数据完整记录在 task.time_log 中,可在导出 JSON 中找到。
- **AC-P5-9** 故意触发 LLM 服务不可用,AI 总结 widget 显示"暂不可用",其他 widget 正常工作。

## 6. 范围

### In Scope
- 时间属性字段、番茄计时、Toggl 集成、重规划建议、Reflect 四 widget、AI 总结(隐私安全)、Reflect 历史。

### Out of Scope(本 phase)
- 智能日程编排(Motion 那种)——明确违反宪章 II
- 自动重规划(必须用户主动触发)
- 团队 Reflect / 协同复盘(超出 v1.0)

---

## 7. 依赖

- **前置 phase**: P0、P1、P2、P3、P4
- **外部**: Toggl API(可选)、本地通知 API(各平台)

## 8. Constitution Alignment

| 宪章条款 | 关系 | 处理 |
|---------|------|------|
| II.1 (时间是属性而非轴) | **核心保护** | FR-P5-002、AC-P5-1 严格守护;唯一例外是用户**主动**添加"时间紧迫程度"轴 |
| II.2 (不基于 deadline 自动排序) | **核心保护** | 重规划必须用户**主动触发**(FR-P5-013) |
| II.5 (Live mode 时间提醒被动呈现) | **直接落地** | FR-P5-003 deadline 提醒默认关;FR-P5-004 不在节点上醒目呈现 |
| IV.2 (Reflect 是核心循环终点,不可降级) | **直接落地** | 本 phase 大半是 Reflect |
| IV.3 (Reflect 必须包含三件事) | **直接落地** | FR-P5-017 四 widget 包含规定的三项 + 演变动画 |
| IV.4 (洞察必须可视化) | **直接落地** | 三个图表 widget + 一句话总结,数据可视化为主 |
| I.1–I.2 (AI 是建议) | **关键保护** | FR-P5-019 强制建议口吻 |
| 隐私 | **加强保护** | FR-P5-025 AI 总结**不**传输 task 原文 |

**潜在张力点**

- **关于番茄计时自动切 status 到 doing**: 这是用户主动按"开始"触发,符合 I.3"用户主动同意"。
- **关于"系统建议重规划"**: 在 FR-P5-013 描述中,系统会在某些情况下**显示"建议重规划"按钮**——这是 visibility(看见 > 自动化),不是自动行为;按钮点不点由用户决定。
- **关于 Reflect 默认时间(周日 20:00)是否过于侵入**: 这是产品默认,但用户可关闭,符合 FR-P5-021。需要在 onboarding 中明确告知用户可调整。

## 9. 开放问题

- **OQ-P5-1** "时间紧迫程度"作为轴时,deadline → 轴值的映射函数:线性 vs 指数 vs 用户自定义?
- **OQ-P5-2** Reflect 弹出在桌面端 vs 移动端的差异化设计(桌面适合长 widget,手机需要纵向流)。
- **OQ-P5-3** AI 总结是否支持多语言(用户的语言)?
- **OQ-P5-4** 7 天演变动画的渲染开销在低配机器上是否可承受?可能需要降级方案。
- **OQ-P5-5** Reflect 历史的清理策略:无限保留 vs 按时间淘汰?(用户隐私视角)
