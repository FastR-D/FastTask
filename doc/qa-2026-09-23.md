## 审查发现与修复

1. 新建目标成功后仍显示旧目标详情：`Goals.createGoal` 未选中新目标；即使选中，PWA 的 `/goals` stale-while-revalidate 快照仍会短暂覆盖新列表。任务树的 Revision 也可能在写入后暂时过期。现在使用创建响应选中，并在目标/任务树变更后以唯一查询参数读取最新列表和树，保留常规请求的离线快照路径。生产浏览器中两层问题均已复现。
2. 手工添加任务成功后，清空的必填控件出现英文原生“Please fill out this field”提示。改为已有的禁用按钮和提交函数校验，避免成功态显示错误。
3. macOS 默认临时目录过长，三个 Unix socket 测试因路径长度失败。测试在 macOS 使用短临时路径。
4. HTTP Agent 测试取消 Worker 后未等待 goroutine 退出，偶发数据库临时目录清理竞态。测试在关闭数据库之前等待 Worker 停止。
5. 文档索引把 Schema 版本写成 5，而仓库已有迁移 8；已校正。
