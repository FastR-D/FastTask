# FastTask UI/UX 统一设计对齐

更新日期：2026-11-10

状态：设计方向已对齐，尚未开始实现。

## 1. 本次目标

FastTask 只在本项目内进行 UI/UX 调整，视觉和交互向 FastRead、FastWrite 的浅色、紧凑研究工作台靠拢。FastNews、FastCAS、FastInsight 作为调研参考，不纳入本次代码改造范围。

本次统一重点是：

- 工作台外壳和导航层级；
- 页面密度、颜色、间距、边框和状态表达；
- 今日任务与 Agent 助手的协作关系；
- 主题切换能力；
- 桌面端与移动端的响应式行为。

不改变任务、排期、Agent、认证和后端 API 的业务语义。

## 2. 系列工具调研结论

| 工具 | 当前结构 | 可借鉴内容 | 本次处理方式 |
| --- | --- | --- | --- |
| FastRead | 左侧导入/历史，中间阅读内容，右侧进度和证据 | 三栏工作台、流程步骤、状态点、紧凑信息层级 | 作为工作台布局参考 |
| FastWrite | 顶部工具栏、文件/大纲侧栏、编辑区、AI 工作区 | 蓝灰 token、44px 顶栏、紧凑控件、工作区分栏 | 作为主要视觉基准 |
| FastNews | 固定侧栏、顶部栏、报告入口和内容卡片 | 导航结构、内容入口、移动端横向导航 | 只借鉴结构，不采用新闻门户风格 |
| FastCAS | 居中容器、表单卡片、安全状态和操作反馈 | 表单、状态和危险操作的清晰表达 | 不改造为 Task 主工作区 |
| FastInsight | 没有独立 Web UI，主要通过飞书机器人交互 | 无直接视觉层参考 | 不纳入视觉统一 |

FastTask 当前已经具备部分基础：

- 使用与 FastWrite 同源的蓝色 `#155fb8`；
- 已定义 4/8/12/16/24/32px 间距 token；
- 桌面端已有导航 Rail，移动端已有 Drawer 和底部导航；
- 目标任务页已有左侧目标列表和右侧任务树；
- 今日工作台已经是任务内容与研究助手的双栏结构；
- Agent 对话在页面切换时保持挂载，避免运行状态丢失。

主要差异在于：FastTask 当前更接近 Material 3 Dashboard，组件圆角、控件尺寸、标题层级和导航表现比 FastRead/FastWrite 更宽松。

## 3. 已确认的产品决策

### 3.1 主导航

桌面端主导航固定为四项：

1. 今日推进
2. 目标任务
3. 复盘
4. 后台作业

“工牌更新”属于设备和外围能力，降为工具或设置入口，不再与核心科研工作流并列。

移动端继续保留现有底部导航能力，并根据空间使用横向或底部形式展示这四个核心入口。

### 3.2 今日工作台

桌面端采用：

```text
左侧导航 + 主工作区 + 默认打开的右侧研究助手
```

右侧助手默认打开。用户可以收起，但不改变 Agent 的持久运行和恢复语义。移动端使用单栏切换，在“今日任务”和“对话”之间切换。

当前 [ResearchWorkspace.tsx](../web/src/ResearchWorkspace.tsx) 已经有双栏基础，第一阶段主要调整外壳和视觉，不重写 Agent 运行逻辑。

### 3.3 登录页

保留当前 FastTask 的深色品牌 Hero 和登录文案。登录页不强行改造成工作台布局，只统一表单、按钮、间距和状态反馈的基础 token。

## 4. 主题模型

视觉主题和颜色模式必须分开管理。

```text
视觉主题：
  workbench  工作台主题，默认
  classic    经典主题，保留当前样式

颜色模式：
  system     跟随系统
  light      浅色
  dark       深色
```

建议使用两个独立的本地存储键：

```text
fasttask.visual-theme = workbench | classic
fasttask.theme        = system | light | dark
```

`fasttask.theme` 是当前已有设置，不能改名或复用。新增视觉主题状态后，两者可以独立组合：

- 工作台 + 浅色
- 工作台 + 深色
- 工作台 + 跟随系统
- 经典 + 浅色
- 经典 + 深色
- 经典 + 跟随系统

### 4.1 默认和兼容策略

- 所有用户默认使用 `workbench`；
- 用户明确选择 `classic` 后持久化该选择；
- 现有亮暗模式偏好继续有效；
- 不删除经典主题 CSS；
- 没有视觉主题存储值时按 `workbench` 处理；
- 首屏脚本必须同时设置颜色模式和视觉主题，避免首次渲染闪烁；
- 跨标签页需要同步视觉主题和颜色模式变更。

建议 DOM 状态类似：

```html
<html class="mdui-theme-auto" data-ft-theme="workbench">
```

当前的 `mdui-theme-auto`、`mdui-theme-light`、`mdui-theme-dark` 继续负责颜色模式，`data-ft-theme` 只负责视觉主题。

### 4.2 主题入口

桌面端导航栏底部从上到下建议为：

```text
用户头像
界面主题按钮  → 工作台 / 经典
颜色模式按钮  → 跟随系统 / 浅色 / 深色
退出登录
```

移动端 Drawer 使用两个带标签的选择器：

```text
界面主题：工作台
颜色模式：跟随系统
```

现有颜色模式控制保留；新增独立的视觉主题控制，不把两个概念合并成一个菜单。

## 5. 工作台主题视觉基准

工作台主题以 FastWrite 的蓝灰 token 和 FastRead 的工作台密度为基准。

```text
画布       #eef0f3 / #f7f8fa
表面       #ffffff
主色       #155fb8
主色悬停   #104a91
正文       #151c28
次级文字   #4b5565
弱文字     #687384
边框       #dfe3e8
成功       #16834a
警告       #8c5b09
错误       #c93636
圆角       5–8px
顶部栏     44–52px
控件高度   28–36px
```

基础规则：

- 页面画布使用浅灰，主要内容使用白色 surface；
- 用细边框和留白表达层级，减少大面积阴影；
- 标题、说明、状态和更新时间使用紧凑的层级；
- 状态统一使用“颜色点 + 文案 + 必要时更新时间”；
- 空状态必须包含下一步动作；
- Agent 回复继续采用文档式排版；审批使用 outlined card；
- 保留浅色、深色和跟随系统能力；
- 第一阶段继续使用 MDUI，通过 token 和布局覆盖实现新主题，不立即替换组件库。

## 6. 页面范围

### 6.1 应用外壳

工作台主题下：

- 桌面端使用完整左侧导航，宽度约 224–248px；
- 顶部栏高度约 44–52px；
- 顶部栏展示当前位置、必要的状态或日期、主题入口和用户操作；
- 移动端使用顶部栏、Drawer 和底部导航；
- 页面内容不因主题切换丢失滚动位置、对话或表单状态。

### 6.2 今日推进

- 左侧主内容展示今日任务、进度、证据和行动；
- 右侧研究助手默认打开；
- 助手可收起，收起后主内容获得更多宽度；
- 移动端在“今日任务”和“对话”之间切换；
- 任务完成、阻塞、取消、等待和失败使用统一状态样式。

### 6.3 目标任务

- 左侧目标列表；
- 右侧任务树、任务详情和甘特图；
- 目标列表、任务树和甘特图共享同一套 surface、边框和状态 token；
- 操作按钮保持紧凑，详情和编辑区域使用明确的层级。

### 6.4 复盘和后台作业

- 使用统一的页面头、说明、筛选器和状态列表；
- 后台作业保留实时连接、更新时间、取消和重试语义；
- 错误、连接中断和空列表使用统一反馈模式。

### 6.5 登录

- 深色 Hero 保持不变；
- 表单卡片、输入框、按钮和错误提示使用新主题的基础尺寸和颜色 token；
- 登录页不显示工作台导航和 Agent 面板。

## 7. 实施边界

本轮不做：

- 不改变后端 API、数据库、任务状态机或 Agent 协议；
- 不改变认证流程和 FastResearch/FastCAS 登录语义；
- 不修改 FastRead、FastWrite、FastNews、FastCAS 的代码；
- 不先抽取跨项目共享 npm 组件包；
- 不删除经典主题；
- 不立即替换 MDUI 或现有图标库。

## 8. 建议实施顺序

1. 扩展主题状态模型，增加 `visual-theme`；
2. 更新首屏初始化脚本和跨标签同步；
3. 增加桌面端和移动端主题切换入口；
4. 新建工作台主题 CSS，先覆盖应用外壳、导航和顶部栏；
5. 调整今日推进和默认打开的右侧助手；
6. 调整目标任务、甘特图、复盘和后台作业；
7. 调整登录表单的基础样式，但保留深色 Hero；
8. 在经典/工作台 × 浅色/深色/跟随系统组合下做回归；
9. 使用 1440px、1024px、390px 三组尺寸进行截图验收。

## 9. 验收重点

- 主题切换不刷新页面；
- 主题切换后颜色模式仍保持原选择；
- 新标签页和刷新后主题保持一致；
- 首屏没有明显主题闪烁；
- 经典主题视觉仍可用；
- 工作台主题下桌面端默认显示右侧研究助手；
- 移动端没有横向溢出；
- Agent 对话、任务表单和甘特图状态不因视觉主题切换而重置；
- 键盘焦点、错误提示、加载状态和深色模式仍可访问。
