# 账号与管理员

本地账号由管理员创建。首次 FastCAS 登录可填写平台登录账号、姓名和本地密码，再经 FastCAS 确认创建并绑定。已有登录账号不会自动合并，应先本地登录再绑定。

FastCAS 已验证用户资料中的 `role=admin` 会在登录或绑定成功时提升对应新账号或已有账号为管理员。普通 FastCAS 角色不会降低平台已有权限，停用账号无法登录。

管理员在「用户管理」搜索、创建及编辑账号，修改登录名、姓名、角色、状态和密码，撤销会话或删除账号。编辑与删除使用 `If-Match` 防止覆盖其他管理员的修改。删除保留业务历史并撤销会话与设备访问。不能删除、停用或降级自己，系统保留至少一名启用的管理员。

注册使用 `GET/POST /api/v1/auth/fastcas/registration`，沿用同源校验及浏览器绑定。账号与待激活绑定在同一数据库事务中写入。已有绑定的激活中断可在后续 CAS 登录时恢复。
