# 甘特图首版测试与部署记录

日期：2026-11-10。

## 实现

- “目标任务”内新增甘特图，与任务树、目标地图并列。
- `milestone` 默认表示阶段，支持先填写阶段周期，再拆分任务。
- 手填日期优先；父项留空时自动汇总子任务，保留未排期提示。
- 支持按月查看、回到今天、折叠阶段、点击编辑和手机横向滚动。
- 展示状态、前置依赖及继承关系，并提示超出阶段、目标期限或依赖日期冲突。
- 计划日期通过任务创建、PATCH、列表、任务树及快照链路读写；显式 `null` 清空，省略字段保留原值。
- 数据库迁移为第 24 版，旧任务的计划日期为空；每日排期继续使用原有规则。
