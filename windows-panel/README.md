# Windows 墨水屏助手

本机助手把 FastTask 的工牌预览发给 WOLINK 800×480 黑白红墨水屏。协议、AES 认证和双平面图像打包参考 `myled/src/wolink_esl`，本目录已包含独立协议实现，不需要依赖 myled 目录运行。

Windows 10/11 开启蓝牙，安装 Python 3.11 或更高版本后运行：

```powershell
# 在克隆后的 FastTask 项目目录中运行
cd .\windows-panel
.\start.ps1 -Install
```

之后运行 `start.ps1` 即可。助手只监听 `127.0.0.1:19743`；页面默认来源为 `http://127.0.0.1:10000`。启动参数 `-Origin` 必须与浏览器打开的 FastTask 页面来源一致。允许有有效证书的 HTTPS 云端域名（可带端口）；HTTP 仅允许 `localhost`、`127.0.0.1` 或 `[::1]`。来源只包含协议、主机和端口，不允许账号密码、路径、查询或片段。不要把助手端口代理到外网。

## 云端部署后的使用

FastTask 的 Web 页面、账号、任务、照片和配对 API 可部署在云端；本助手仍运行在用户的 Windows 笔记本上，通过本机蓝牙连接墨水屏。云服务器无需蓝牙，也不能直接连接用户身边的设备。页面向本机助手发送预览；关闭页面后，助手在定时时点通过 HTTPS 向配对的云端 FastTask 读取今日快照并写屏。云端部署不需要改变其它业务模块。

假设云端页面为 `https://fasttask.example.com`，在 Windows 上首次安装并启动：

```powershell
.\start.ps1 -Install -Origin "https://fasttask.example.com"
```

在 Edge 或 Chrome 中打开该云端地址，进入 **pannel**，连接本机助手并选择墨水屏。浏览器询问本地网络访问权限时，允许该可信页面访问本机助手；设备与当前云端账号完成配对后，默认按三个固定时点自动刷新，无需另开定时设置。云端仍需通过正常的 HTTPS 证书校验，快照端点必须直接响应 `/api/v1/panel/snapshot`，不能重定向到另一个地址。普通浏览器不支持或禁止本地网络访问时，应先使用 Windows 的 Edge/Chrome 并检查该站点权限。

确认可以使用后，安装相同云端来源的当前用户登录自启：

```powershell
.\install-autostart.ps1 -Origin "https://fasttask.example.com"
```

安装自启不会立即重启已有助手。若本机助手已用本地地址启动，先退出对应的助手进程，再按新来源启动；同一端口只运行一个实例。云端页面的 CSP 必须允许连接 `http://127.0.0.1:19743`，不能由反向代理覆盖为仅 `connect-src 'self'`。本机端口不应暴露到公网。

当启动来源从本地地址变为云域名，或从一个域名变为另一个域名，助手会关闭自动刷新、清除旧账号配对凭据和设备选择，并要求登录新来源重新配对；旧凭据不会发送给新服务器。协议或非默认端口改变也视为新来源。等价写法会统一规范化，例如 `https://FASTTASK.example.com:443/` 与 `https://fasttask.example.com` 相同。也可给不同环境使用不同 `-StateDirectory`，自启脚本支持同名参数；此目录含私密凭据，不应提交或同步到公开位置。更换来源不会修改云端任务或其它业务数据。

依赖已锁定为实机验证版本，包含 WinRT 3.2.1 全套运行库，避免安装时隐式升级 Windows 蓝牙接口。首次扫描等待约三十秒，设备广播较慢时请保持靠近直至扫描结束。

在 FastTask 的 **pannel** 页上传或更换照片、修正显示内容，选择自己墨水屏的广播名称与对应 MAC 地址。工牌包含全部当前今日任务，按 FastTask 源顺序排列；不再使用旧版任务勾选或显示排序设置。完成情况从 FastTask 读取，任务操作仍在原工作台进行。每次发送都重新核验广播名、地址和 WOLINK GATT 服务。全部数据包通过 GATT 应答，并收到准确的 `ff00000000000000` 完成通知后，接口才报告成功。未收到确认、断连、写入超时均报告失败，不自动重发。

设备与账号完成配对后，助手默认在 **Asia/Shanghai 每日 14:00、17:30、21:00** 查询 FastTask 新快照及东西湖区天气，读取真实今日任务状态，渲染后写屏。页面关闭不影响此进程工作；电脑必须开机、未休眠、FastTask 服务及助手运行、蓝牙开启且设备在附近。已完成、未完成、已跳过均保留真实状态；仅不显示被新版替代的旧任务项。不会推断或修改任务状态，也不需要在 pannel 内手动确认完成。

关机/休眠错过多个时点时，恢复后仅补当天最近一个时点；历史日期不补发。同一个时点失败也不自动重复写入，在页面查看真实失败原因并手动重试，或等待下一时点。重启前先记录尝试时点，避免电源中断造成自动重复发送。超过 3 行的任务完整连续分页，屏幕页脚仅显示页码；定时默认发第 1 页，可在配置中指定固定页码，若该页已不存在则回到第 1 页。

头像等比缩放完整保留、白底填充，再转换黑白红抖动；不会裁切证件照。天气请求失败会显示不可用/缓存标记，手动天气修正带手动标记。画面不显示座位或额外的状态解释。

可选安装当前 Windows 用户登录自启（无管理员权限）：

```powershell
.\install-autostart.ps1
# 移除登录自启：
.\install-autostart.ps1 -Remove
```

助手第一次启动尚未配对，不执行刷新；页面选择设备并配对当前账号后默认启用固定时点，无需另行勾选。首次或变更配对会先只读查询一次当日快照，验证成功后原子保存；凭据失效或网络失败时保留原配置，不发屏。配对凭据仅可读取该账号的工牌快照，保存到本目录被 Git 忽略的 `.state/config.json`；目录 ACL 限制当前用户，不打印凭据，不向网页返回凭据。内部管理仍兼容显式 `enabled:false`，重启保留停用状态。凭据过期/撤销后显示重新配对提示。`status.json` 记录最近操作、时点和真实结果，不含凭据或头像。

API 固定只接受配置的 FastTask Origin，校验 Host，写操作只接受 JSON，限制请求/图像大小，不允许网页指定任意上游地址。CORS/Private Network 预检仅对允许的页面来源返回授权头；无 Origin 请求只可读取脱敏健康状态与配置。FastTask 快照请求关闭系统代理及重定向，始终校验 HTTPS 证书和主机名，避免凭据泄露。配置接口不能更换上游地址，切换来源必须重新启动并重新配对。

| 接口 | 请求与结果 |
|---|---|
| `GET /health` | 版本、蓝牙支持、busy、脱敏配置、上次状态和下次时点 |
| `GET /config` | 不含凭据的配置，`has_token` 仅表示已保存 |
| `POST /scan` | `{device_name?: string}` → `devices:[{name,address,rssi}]` |
| `POST /send` | `{device_name,address,image_base64}` → 准确通知、应答包数 |
| `PUT /config` | `{device_name,address,panel_token,pairing_id,fasttask_url,page,enabled?}`；完整配对省略 `enabled` 时默认启用；`page` 从 0 开始 |
| `POST /refresh` | `{}` → 实时读取快照、渲染、发送并回报实际结果 |

本机服务地址由启动参数固定，配置不能把配对凭据转发到其他地址。`image_base64` 接受 PNG/JPEG base64 或 data URL，要求 800×480、解码后不大于 1 MB。

测试（不发送真实蓝牙）：`python -m unittest discover -s tests -v`。在已有依赖的开发机器，也可 `start.ps1 -DependencyPath <依赖目录>`，正式独立部署推荐 `-Install`。
